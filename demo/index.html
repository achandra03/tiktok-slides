TikTok integration demo

End-to-end walkthrough of how FitLens Poster uses TikTok's Login Kit and Content Posting API to publish photo carousels to @casey.gym.lifts.

Product: Login Kit

Step 1 — Connect the TikTok account

The account owner authorizes FitLens Poster via TikTok's official OAuth flow. Requested scope: user.info.basic

Redirecting to TikTok authorization:
https://www.tiktok.com/v2/auth/authorize/?client_key=…&scope=user.info.basic&response_type=code&redirect_uri=https%3A%2F%2Fhttpbin.org%2Fget

The owner approves @casey.gym.lifts on tiktok.com, then TikTok returns an authorization code that is exchanged for access & refresh tokens.
✓ Connected as @casey.gym.lifts — scope granted: user.info.basic
Content preparation

Step 2 — Build the carousel

FitLens Poster renders 1080×1920 slides (Pinterest-sourced imagery, TikTok-native burned-in text), uploads them to this site's hosting, and composes the caption.

Caption: 3 form mistakes secretly killing your glute gains 🍑
Hashtags: #gymgirl #glutegrowth #glutes #gluteworkout #gymtok #formcheck
Product: Content Posting API

Step 3 — Publish via API

Direct post as a photo carousel. Requested scope: video.publish. Images are pulled by TikTok from the verified URL prefix on this domain (PULL_FROM_URL, mode DIRECT_POST).

What this demo showed

  • Login Kit (user.info.basic): OAuth authorization of @casey.gym.lifts.
  • Content Posting API (video.publish): DIRECT_POST photo carousel via PULL_FROM_URL from the verified domain.
  • Posts publish as Private (SELF_ONLY) while the app is in sandbox; public posting unlocks after audit.
